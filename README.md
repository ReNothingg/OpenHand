# OpenHand

**Ваш текст. Ваш почерк. На экране и на бумаге.**

Редактор рукописных документов, студия шрифтов и управление перьевым плоттером.

[Открыть в браузере](https://renothingg.github.io/OpenHand/) · [Релизы](https://github.com/ReNothingg/OpenHand/releases) · [Видеообзор](https://www.youtube.com/watch?v=TxZVIGn5Rf8)

macOS · Windows · Web

## От текста к рукописной странице

Напишите текст в Markdown или LaTeX, выберите почерк и настройте лист.
OpenHand разложит материал по страницам и покажет результат до печати.
Готовый документ можно сохранить в PDF, экспортировать в G-code или написать
на бумаге совместимым плоттером.

Редактор, встроенные шрифты и расчёт траекторий работают локально.

## Возможности

| | |
| --- | --- |
| **Документы** | Markdown, LaTeX, формулы, списки и таблицы; импорт XLSX, CSV и TSV |
| **Страницы** | A4, A5, Letter и тетрадный разворот; поля, интервалы и ручная раскладка |
| **Почерк** | Локальные шрифты, авторские профили, варианты букв и соединения |
| **Свой шрифт** | Рисование пером или мышью, импорт фотографии и бланка, формат `.gfont` |
| **Графика** | SVG, DXF, векторизация изображений и мастерская траекторий |
| **Плоттер** | GRBL, Marlin и EBB; USB / Bluetooth Serial и TCP в настольных приложениях |
| **Экспорт** | Печать, PDF, G-code, собственные шрифты и настройки |

## Быстрый старт

1. Введите текст во вкладке **«Документ»**.
2. Выберите шрифт, размер листа и поля.
3. Откройте **«Почерк»**, чтобы настроить характер письма.
4. Проверьте страницы и сохраните PDF либо подготовьте запись на плоттере.

Для печати подходит экранный шрифт. Для движения пера нужен однолинейный
**GFont**: встроенный или ваш собственный.

## Повторяющиеся буквы с разным характером

Включите **«Настоящий почерк»** и настройте **«Автоварианты формы букв»**.
Для GFont меняются очертания петель, дуг и хвостов, а не только размер или толщина
линии. Если в шрифте записано несколько начертаний, OpenHand выбирает их с учётом
положения в слове и добавляет плавные изменения геометрии.

Автоварианты строятся из исходного начертания и сохраняют его узнаваемость.
Новые штрихи не дорисовываются. Оригинальный файл шрифта остаётся прежним.
Один алгоритм используется в документе и предпросмотре студии шрифтов;
в студии значение **0%** показывает записанные формы без автоматического изменения.

Результат воспроизводим: одинаковые текст, настройки и зерно случайности дают
одинаковую траекторию. При обновлении предпросмотра буквы не меняются сами собой.

## Студия шрифтов

Откройте **«Создать свой шрифт в мастерской»** рядом с выбором шрифта.
Нарисуйте символы, загрузите фотографии или заполненный бланк. Для одной буквы
можно сохранить несколько начертаний и указать варианты для начала, середины
или конца слова.

Студия поддерживает редактирование узлов, отмену, предпросмотр фразы и экспорт
`.gfont`. Черновик сохраняется локально; экспортируйте файл, чтобы иметь отдельную копию.

## Работа с плоттером

Все параметры устройства находятся во вкладке **«Плоттер»** и используются
документом и мастерской совместно.

1. Выберите профиль контроллера и подключение.
2. Задайте направления и размеры рабочей области.
3. Сохраните положения пера **над бумагой** и **на бумаге**.
4. Привяжите документ к бумаге, проверьте рамку и запустите запись.

В блоке **«Что находится под пером?»** выберите один режим:
**«Первый штрих текста»** для письма прямо от выбранной точки или
**«Левый верхний угол бумаги»** для размещения с полями документа.
Нажмите единственную кнопку **«Запомнить эту точку»**, затем **«Начать запись»**.
При смене режима прежняя привязка снимается; новое положение применяется только
после запоминания. Запоминание только задаёт координаты X/Y, не двигает механизм
и не меняет высоту пера. Привязка первого штриха доступна
для GRBL и Marlin, без пользовательских стартовых команд.

Скорость письма, холостой ход и скорость подъёма пера регулируются отдельно.
Назначение начала листа меняет только XY. Оно не меняет высоту пера.

**СТОП** и **Esc** отменяют очередь. В настольных приложениях остановка также
доступна через меню «Плоттер». Программная остановка зависит от связи с устройством:
если механизм продолжает движение, отключите питание. Первую проверку выполняйте
короткими перемещениями, вдали от механических упоров.

## Где запускать

| Версия | Подключение плоттера |
| --- | --- |
| **macOS** | Нативный последовательный порт и TCP |
| **Windows** | Нативный последовательный порт и TCP; требуется WebView2 Runtime |
| **Браузер** | Web Serial в поддерживаемом настольном браузере, по HTTPS или localhost |

Редактирование документов, PDF и студия шрифтов доступны без подключённого плоттера.

## Разработка и сборка

Нужны Node.js и npm. Для приложения macOS также нужен полный Xcode;
для Windows — .NET 8 SDK или совместимый SDK с поддержкой целевой платформы.

```sh
npm ci
npm run dev
```

| Команда | Результат |
| --- | --- |
| `npm run typecheck` | Проверка TypeScript |
| `npm run build` | Сайт и настольное приложение для текущей ОС |
| `npm run build:web` | Сайт в `docs/` |
| `npm run macos:build` | Универсальный `macos/build/OpenHand.app` |
| `npm run windows:build` | Windows x64 в `windows/build/` |
| `npm run windows:build:arm64` | Windows ARM64 |
| `npm run verify:web-sync` | Проверка совпадения web-ресурсов сайта и macOS |

`src/` содержит общую логику и интерфейс, `macos/` и `windows/` — нативные оболочки.
`font/` и `public/` хранят локальные ресурсы. `docs/` — готовый сайт GitHub Pages;
эту же сборку использует Windows. `macos/Web/` синхронизируется при сборке.
