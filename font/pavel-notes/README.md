# Личный почерк: источники и воспроизведение

Профиль **По умолчанию** использует локальный `pavel-notes.gfont` в web,
macOS и Windows. В нём 100 знаков: повседневные формы из конспектов
IMG_0839–IMG_0850 и целые буквы автора из заполненного бланка для остальных
заглавных, редких строчных, цифр и пунктуации. Белорусские і/І сохранены
из предыдущего набора. Полной латиницы в исходных образцах нет.

## Фотографии конспектов

Со всех 12 снимков размечены 90 строк. Строка делится на слова по самым
широким промежуткам, затем для каждого слова предлагаются базовая линия,
высота строчных, наклон и границы букв. Все буквы прошли визуальную
проверку на наложениях и в таблицах вариантов. Принято 162 слова; в шрифт
включены 275 начертаний. Точный список и источник каждого варианта записаны
в `coverage.json`. Отклонены формы с частью соседней буквы или строки,
оборванные петли, неверные границы, латиница из формул и цифры с неточной
базовой линией. Их исходная разметка остаётся в `notebook-words.json`.

Чернила отделяются по отражению красного света от локального фона бумаги.
Для светлых чернил и маркера используются отдельные пороги. Центральные
линии извлекаются из маски; короткие отростки скелета у пересечений
(артефакты утончения капель чернил) удаляются, петли и выносы сохраняются.

Масштаб фотографии оценён по клетке 5 мм или шагу линейки. Для сборки
используется один масштаб на слово, с общей высотой тела 200 единиц GFont
(4,23 мм при 32 px). Отдельные буквы не выравниваются по своему габариту.
Сохраняются боковые выносы, шаг до следующей буквы, положение в слове,
соседние буквы и наблюдаемые точки соединения. Наклон слова приводится
одним сдвигом к медианному наклону автора. Сглаживание ступенек ограничено
0,045 мм в координатах вырезки.

На символ выбирается до двенадцати реально написанных вариантов: обычная
форма, до трёх окончаний и начал, затем соединённые формы с разных страниц.
Повторяющаяся буква в тексте поэтому редко повторяет один и тот же контур. В новых сочетаниях движок
предпочитает наблюдаемые точки соединения и использует поиск по геометрии,
если такого сочетания в образцах нет. Для заглавных отсутствие записанной
точки сохраняет отрыв пера. Это реконструкция по статичным снимкам:
исходная скорость, порядок проходов и физический нажим не измерены.

## Бланк автора

`sheet-strokes.json` хранит 210 целых начертаний из двух страниц заполненного
PDF: 34 строчные по три варианта, 34 заглавные по два, 10 цифр по два и
20 знаков. Источник — сохранённые центральные траектории PencilKit, а не
растровая обводка. Все 269 штрихов, их порядок и относительные давление
и время сохраняются. UUID аннотаций, имя и абсолютные даты не включены.

Отдельный профиль **Из заполненного бланка** и `pavel-samples.gfont`
сохранены. Его сборка `npm run font:samples` проверяет все точки после
экспорта и обратного преобразования в координаты бланка. Эта проверка
показывает сохранность геометрии, а не сходство связного текста.

## Чернила и бумага

По умолчанию используются синие чернила, линия 0,32 мм, размер 32 px и
межстрочный шаг около 10 мм. Автоварианты формы ограничены 4%, ритм — 12%,
колебание строки — 8%; разброс пробелов — 24%. Повторения используют реальные
начертания, а не только случайный размер. Все решения воспроизводимы по seed.
Перед переносом пробелы строки сокращаются не больше чем на четверть
(на 30% при максимальном умещении), затем сужаются буквы: на фото слова
у края строки остаются явно разделены.

Ширина линии плавно меняется вдоль штриха. Это модель шариковой ручки,
основанная на направлении, изгибе и плавной вариации, а не восстановленное
давление с фотографии. Контур чернил вычисляется одним SVG-путём на штрих,
без градиентов и без множества элементов на каждый отрезок. На физическую
траекторию настройки **Толщина линии**, **Колебание толщины** и **Фактура
бумаги** не влияют. Изменение аппаратного давления по умолчанию отключено.
Ширина на настоящем листе зависит от ручки. Текстура хранится локально в
`public/textures/paper-grain.svg`; внешних ресурсов для почерка нет.

Нетронутые старые настройки профиля обновляются автоматически. Ручные
значения и документы сохраняются. Применить весь новый набор:
**Почерк → Профиль автора → По умолчанию**. Сохранённая ручная реконструкция
доступна отдельным профилем. Скорость и калибровка устройства не меняются.

## Воспроизведение и проверка

- `notebook-words.json` — хеши источников, кадры слов, масштаб, границы,
  исключённые области и список допущенных букв.
- `notebook-strokes.json` — центральные траектории в миллиметрах.
- `scripts/trace-notebook-pages.py` — извлечение с локальных декодированных
  PNG/JPEG; `propose` делит строки на слова и создаёт наложения, `refine`
  уточняет базовую линию и высоту по буквам внутри проверенных границ,
  `trace` принимает только проверенные слова.
- `scripts/notebook-letter-forms.mjs` — масштаб, смещения, соединения,
  сглаживание и отбор вариантов.
- `coverage.json` — покрытие и происхождение; `handwriting-settings.json`
  и `writing-config.json` — значения профиля.
- `specimen.svg`, `variants.svg`, `writing-sample.svg`, `writing-preview.png`
  — образцы для визуального сравнения.

`npm run font:pavel` воспроизводит шрифт и SVG без исходных фотографий.
`npm run build` собирает web и доступную нативную платформу; macOS включает
копию `docs` в `macos/Web`, Windows включает тот же `docs` через проект .NET.
Синхронизацию пакетов проверяет `npm run verify:web-sync`.

Первичные фото и PDF остаются вне репозитория. Сходство страницы 1:1 и
физическое письмо не подтверждены. Старые `raster-*`, `photo-traces.json`,
`spacing-adjustments.json`, `audit-cases.json` и `validation.json` относятся
к предыдущей оцифровке IMG_0589; её замеры не являются оценкой нового шрифта.
