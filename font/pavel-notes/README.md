# Личный почерк: источники и проверка

Профиль **По умолчанию** использует локальный `pavel-notes.gfont` в macOS
и Windows. Набор содержит 98 знаков. Предыдущая версия сохранена отдельно
в `pavel-notes-legacy.gfont` и доступна через профиль **Прежняя реконструкция**.

## Новая оцифровка

Для 31 строчной русской буквы и прописных Г/В получены 57 начертаний
непосредственно из чернил на IMG_0589. Изображение отделяется от сетки,
линии утончаются до центральных траекторий, замкнутые петли сохраняются
целиком. Границы букв в связных словах размечены вручную. В набор включены
отобранные фрагменты; наличие тёмных пикселей само по себе не означает,
что фрагмент подходит как буква.

Каждое начертание хранит начало отсчёта на базовой линии, шаг до следующей
буквы, источник, соседние буквы и точки соединения. Это сохраняет выносы
и боковые смещения: левый край чернил больше не становится автоматически
началом каждой буквы. Соединение может приходить во внутреннюю точку
штриха. Такой штрих не склеивается с соединением через неверный конец.

Конечная форма не попадает в середину слова. Для оцифрованных форм совпадение
соседних букв имеет приоритет перед случайным выбором. Варианты и небольшие
изменения формы по seed сохраняются. Ступеньки растра сглаживаются с пределом
смещения 0,6 пикселя исходной вырезки; координаты не заменяются произвольными
каллиграфическими кривыми.

Остальные прописные, цифры, пунктуация и ъ пока взяты из прежней ручной
реконструкции. Ё/ў составлены из новой основной буквы и отдельного знака.
Прописные ЖХЦШЩЪЫЬЭЮ остаются предположительными формами. Полной латиницы нет.
Статичная фотография не даёт исходный порядок движений, скорость и давление;
порядок проходов восстановлен по графу линий. **Копия 1:1 не подтверждена.**

## Размер, интервалы и настройки

Масштаб оценён по тетрадной сетке: около 5,2 пикселя на миллиметр при клетке
5 мм. Перспектива и изгиб страницы остаются источниками ошибки. Новые формы
используют одинаковый масштаб по X/Y; размер отдельных букв не выравнивается
по их собственному ограничивающему прямоугольнику.

Стартовые параметры: 32 px, ширина 100%, строки 1,18, вариативность 4%,
связность 100%, ритм 12%, колебание строки 8%, согласованность 100%.
Размеры пробелов — 86% с разбросом 24%. Шаги букв скорректированы по 20
исходным словам регуляризованной подгонкой с ограничением изменения 22% от медианного шага буквы.
Это корректировка интервалов, а не растягивание контуров букв.

Перед переносом движок сокращает свободные пробелы, затем ширину букв
в пределах общего лимита на всю строку (по умолчанию 20%). Высота сохраняется;
повторного сжатия уже сжатой строки нет. Явные переводы строки сохраняются.
Формулы и рисунки сохраняют отдельную раскладку.

Нетронутый предыдущий профиль обновляется автоматически. Ручные настройки
существующих документов сохраняются. Полностью применить новый набор:
**Почерк → Профиль автора → По умолчанию**. Вернуться к прежнему:
**Почерк → Профиль автора → Прежняя реконструкция**.

Скорость письма 1800 мм/мин, интервал 0,1 мм и настройки устройства не менялись.
Выбор профиля ничего не отправляет на плоттер. Физическое письмо не проверено.

## Проверка результата

В `validation.json` сохранены результаты сравнения с прежней версией.
Четыре контрольных слова не участвовали в выделении букв или подгонке
интервалов: «сохранение», «определенной», «оползни», «вулканов».
Среднее абсолютное расхождение их ширины снизилось с 16,7% до 10,7%.
Два слова улучшились, два ухудшились; это явно отражено в отчёте.

**Ошибка ширины не является процентом сходства.** Для оценки формы нужны
наложения на оригинал. Начала и базовые линии совмещаются переносом;
масштаб общий, отдельные слова и буквы не растягиваются и seed не перебирается.
Исходная страница использовалась при оцифровке, поэтому даже контрольные
слова не являются независимой проверкой на другом почерке или другой странице.

## Воспроизведение

- `raster-segments.json` — источник, масштаб, вырезки и границы букв.
- `raster-strokes.json` — траектории в координатах фотографии; снимок для сборки не нужен.
- `spacing-adjustments.json` — поправки шага букв в пикселях источника.
- `photo-traces.json` / `strokes.json` — прежние ручные формы для оставшихся знаков.
- `coverage.json` — точное покрытие и происхождение.
- `handwriting-settings.json` / `writing-config.json` — настройки.
- `specimen.svg`, `variants.svg`, `writing-sample.svg`, `writing-preview.png` — образцы.

`npm run font:pavel` воспроизводит GFont, настройки и SVG.
`npm run font:audit -- --output /local/review --reference /local/page-crop.jpg`
строит наложения прежней и новой версии и JSON с замерами. Фотография
необязательна; ожидается правая страница IMG_0589: исходник уменьшен до
1824×1368, вырезка x=880, y=175, 910×1125. Снимки в репозиторий не включены.

Для повторного выделения чернил нужен декодированный полный PNG/JPEG,
Python 3 с Pillow и NumPy:

```sh
python3 scripts/trace-notebook-ink.py --image /local/IMG_0589.png --review-dir /local/ink-review
npm run font:pavel
rsvg-convert -o font/pavel-notes/writing-preview.png font/pavel-notes/writing-sample.svg
```

`npm run build` собирает интерфейс, синхронизирует `macos/Web` и собирает
приложение текущей платформы. Windows включает тот же пакет `docs` как `Web`.
Для Windows EXE требуется `npm run windows:build` на Windows.
