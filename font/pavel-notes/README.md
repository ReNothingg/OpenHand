# Почерк по умолчанию

Профиль создан по визуальному разбору 14 фотографий IMG_0492–IMG_0505.
Это ручная реконструкция осевых линий, а не точная автоматическая обводка
каждого пикселя и не запись движений руки. Сходство с оригиналом на бумаге
пока не проверено. Фотографии не включены в репозиторий.

## Что изучено

| Фото | Образец | Использованные признаки |
| --- | --- | --- |
| 0492 | Белорусская литература, заголовки, таблица | Прописные Б/К/Р, верхние петли, плотное письмо в узких колонках |
| 0493–0494 | Белорусский связный текст | і/ў, длинные д/у/з, изменения формы а/е/о, тесные соединения |
| 0495–0497 | Русские упражнения | т/ш/щ, ь/ы, выносные элементы, компактный размер тела букв |
| 0498 | Средства связи предложений | Быстрое письмо, широкие м/т, длинные нижние штрихи |
| 0499 | Механические колебания | Основной образец строчных: наклон вправо, открытые соединения, узкие овалы |
| 0500–0501 | Определения и формулы | Прописные, цифры, соотношение тела буквы и межстрочного интервала |
| 0502–0503 | Общество, социальные роли | Варианты а/е/о/н, заметные верхние петли, сгущение окончаний |

По разлиновке визуально оценены: тело строчной примерно 3–4,5 мм,
верхние выносы примерно 1,6–1,9 высоты тела, нижние — до одной высоты тела.
Это ориентиры, а не инструментальные измерения: присутствуют перспектива,
кривизна листа, просвечивание оборота и разные ручки.

## Использование

В документе: **Почерк → Профиль автора → По умолчанию**.
Профиль выбирает собственный GFont и настройки письма. Он также устанавливает
скорость 1800 мм/мин, межбуквенный интервал 0,1 мм, сохраняет порядок штрихов
и включает уплотнение G-code. Это стартовая конфигурация для пробы, не
измеренная оптимальная скорость устройства. Положения Z/servo, ход пера,
оси, размеры области, подключение, нули и калибровка не изменяются.

Размер 27 px при 400 единицах em и теле 220 единиц даёт тело около 3,9 мм;
межстрочный шаг 1,4 даёт около 10 мм. Для тетради в линейку уменьшайте
размер и шаг вместе. Наклон уже заложен в траекториях: дополнительный наклон
профиля равен нулю. Случайное изменение форм ограничено 18%, чтобы не
искажать исходные буквы. Давление и скорость руки по фото не измерены;
давление не имитируется случайным утолщением.

Сначала запишите короткую строку из `sample.txt` привычной ручкой, сравните
размер, наклон, пробелы и высоту нижних петель. Затем меняйте по одному
параметру. Перед запуском используйте существующую проверку рамки и пера.
Новая конфигурация сама ничего не отправляет на плоттер.

## Состав и границы

98 знаков: русский алфавит, белорусские Іі/Ўў, цифры и основные знаки.
У а/е/о/и/н/т/с/я — две отдельно нарисованные формы, а не два случайно
растянутых дубля. Латиница и полный математический алфавит не оцифрованы;
дополнительные математические символы обрабатываются существующим движком.
Неподдерживаемые символы следует проверять в предупреждениях документа.

Прописные ЖХЦШЩЪЫЬЭЮ реконструированы увеличением родственных строчных:
чистых самостоятельных образцов для уверенной оцифровки не выбрано.
Ё/Й/Ў и точки і построены из тела и отдельных надстрочных штрихов.
Все траектории являются интерпретацией, включая направление и порядок
движения на пересечениях: статичная фотография их однозначно не задаёт.

## Дальнейшее уточнение по оригиналам

**Создать свой шрифт → Открыть .gfont**: выберите `../plotter/pavel-notes.gfont`.
Выберите букву и нужное начертание, затем **По фотографии → Буква из конспекта**.
Загрузите локальный JPEG/PNG, выделите букву вместе с хвостом и точками,
задайте верх тела и базовую линию. Фильтр синей ручки помогает убрать
разлиновку; порог регулируется вручную. Проверьте результат до применения.
Можно записать вариант в отдельное начертание. Исправления отменяются
обычным Undo редактора. HEIC предварительно экспортируйте в JPEG/PNG,
если браузер его не открывает.

Рамка не исправляет перспективу и не разделяет связные буквы автоматически.
В местах соединений понадобится редактор фрагментов и точек. Направление
штрихов после скелетизации также следует проверить. Длина хвоста сохраняется
относительно выбранной базовой линии; прежнее привязывание нижней точки
вырезки к строке в этом режиме не применяется.

## Исходники и воспроизведение

- `strokes.json` — редактируемые кривые осевых линий.
- `coverage.json` — покрытие, альтернативы и предположительные прописные.
- `handwriting-settings.json` — импортируемые настройки документа.
- `writing-config.json` — только параметры письма, не полный профиль устройства.
- `specimen.svg` — атлас знаков с базовой линией.
- `writing-sample.svg` — текст, полученный настоящим движком компоновки.

`npm run font:pavel` пересобирает GFont, настройки и оба SVG. Команда включена
в `npm run build:web`, поэтому обе платформы используют один и тот же ресурс.
macOS получает `macos/Web`, Windows упаковывает `docs` как `Web` через MSBuild.

Проверены чтение всех русских/белорусских букв и цифр, загрузка альтернатив,
компоновка образца, конечность координат, компиляция G-code и сохранение
нижнего выноса при импорте. Проверка на физическом плоттере не проводилась.

Новые документы и сброс настроек выбирают этот профиль автоматически.
Сохранённые пользовательские настройки продолжают действовать; чтобы применить
новую скорость к существующему документу, выберите «По умолчанию» ещё раз.
Скорость движения по линиям увеличена с 900 до 1800 мм/мин; общее время
записи не уменьшается строго вдвое из-за подъёмов пера и холостых перемещений.
Старые внутренние идентификаторы сохранены для совместимости. Название профиля
обозначает стартовую настройку приложения, а не универсальность почерка.
