# Персональный почерк

macOS использует общий профиль «По умолчанию» и инструмент
«Буква из конспекта». Шрифт и интерфейс попадают в `Web` через общий build.
Шрифты и фотографии обрабатываются локально.

Исходники, настройки, образцы и ограничения: [font/pavel-notes](../font/pavel-notes/README.md).
Сборка: `npm run build`; синхронизация ресурсов: `npm run verify:web-sync`.

Обновление по IMG_0589–IMG_0601: 113 оцифрованных начертаний, варианты
окончаний и профиль 32 px / 1,18, ширина 82%. Новые документы используют его автоматически;
нетронутые настройки прежней версии обновляются без изменения калибровки.

У 41 знака есть альтернативы. Индивидуальные интервалы форм сохраняются
в GFont; расчёт переносов учитывает выбранную форму и длинные петли.
Ручные настройки существующих документов сохраняются.
