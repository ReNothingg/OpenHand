# Личный почерк

macOS использует общую реализацию GFont и пакет `Web` из `npm run build`.
Профиль «По умолчанию» включает траектории чернил 33 символов из конспекта,
исходные боковые смещения, соединения во внутренних точках штриха и
контекстный выбор форм. Прежняя версия доступна отдельным профилем.

Нетронутые настройки мигрируют; ручные изменения сохраняются. Предпросмотр
мастерской учитывает полную высоту выносов. Умещение слов использует общий
лимит сужения строки и одинаково работает в предпросмотре и G-code.

[Источники, настройки, воспроизведение и ограничения](../font/pavel-notes/README.md).
Проверка ресурсов: `npm run verify:web-sync`. Физическое письмо не проверено.
