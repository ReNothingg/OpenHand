# OpenHand для macOS

Нативное приложение использует локальную веб-сборку OpenHand внутри `WKWebView`.
Последовательный порт подключается напрямую через macOS (`/dev/cu.*`), поэтому
Chrome, Edge и Web Serial не требуются.

## Подготовка ресурсов

Из корня проекта:

```sh
npm install
npm run macos:sync
```

Команда собирает React-приложение и копирует полностью локальную сборку в
`macos/Web`. После этого откройте `macos/openhand.xcodeproj` в Xcode и запустите
схему `openhand`.

Для готовой Release-сборки можно выполнить:

```sh
sh macos/scripts/build-release.sh
```

Универсальное приложение для Apple Silicon и Intel появится в
`macos/build/OpenHand.app`.

## Поддерживаемое соединение

- 8 бит данных, 1 стоп-бит, без чётности (8N1);
- 9600, 115200 и 250000 бод;
- управление DTR и RTS;
- GRBL, Marlin и EBB / DrawCore;
- пауза, продолжение, аварийная остановка и восстановление задания.

Если порт не появляется в списке, установите драйвер USB-UART производителя
устройства и переподключите контроллер.

Smoke-тест нативного последовательного слоя запускается командой:

```sh
sh macos/scripts/test-serial-smoke.sh
```
