# Иконки интерфейса

Каждый SVG-файл используется напрямую из `/icons`. Чтобы заменить иконку, сохраните новый SVG под тем же именем.

- Используйте `viewBox="0 0 24 24"`.
- Рисуйте иконку чёрным цветом на прозрачном фоне.
- Цвет в интерфейсе применяется автоматически через CSS-маску.
- Не меняйте имя файла, если не хотите править компонент.

`panel-*-collapse.svg` показывается при открытой панели, `panel-*-expand.svg` — при свёрнутой.
