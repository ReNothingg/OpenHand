# GRBL-Plotter: функциональное покрытие OpenHand

Проверено 19 сентября 2026. Репозиторий https://github.com/svenhb/GRBL-Plotter
склонирован для анализа, ревизия `20d574c960a2f1c351cbc5e8818db6e463abf8c3`.
Инвентаризация: 214 файлов C#, 187 434 строки, включая дизайнерские файлы и
встроенные сторонние библиотеки. Это не заявление о построчном аудите всех файлов.
Прямое копирование исходников в OpenHand не выполнялось; текущая реализация
написана для общего React/TypeScript-ядра и двух существующих нативных оболочек.

## Что добавлено

| Область | Реализация | Граница поддержки |
| --- | --- | --- |
| Рабочее пространство | Отдельные «Документ» и «Мастерская плоттера», без потери активного подключения при переключении | Переключение запрещено во время задания и калибровки |
| Геометрия | Прямоугольник, эллипс, треугольник, линия; масштаб, поворот, отражение, смещение, отступ | Преобразуются штрихи рисунка, не произвольный машинный G-code |
| HPGL/PLT | IN, PA, PR, PU, PD, SP, VS, PW, AA, AR, CI; 40 единиц/мм | Один инструмент; SP/VS/PW не переключают физическое перо и не меняют профиль скорости/толщины. Остальные команды отклоняются, не пропускаются |
| CSV/TSV координат | X,Y в мм, необязательная первая строка x,y, пустая строка поднимает перо | Не табличный документ XLSX; его существующий импорт остаётся в редакторе |
| Штриховка | Заданный угол/шаг, правило чётности для отверстий, чередование направления | Только замкнутые контуры; пересечения трактуются по правилу чётности |
| Повторы | Сетка до 20×20 с интервалом в мм | Ограничение общего количества точек и проверка границ механики |
| Проекты | Локальный черновик, JSON импорт/экспорт, отмена/повтор, экспорт SVG и G-code | До 100 000 точек; история хранится только в текущем сеансе мастерской |
| Почерк и графика документа | Перенос штрихов текущего листа в мастерскую | SVG/DXF/фото сначала импортируются через существующий редактор документа |
| Редактор G-code | Изменение текста, применение с пересчётом предпросмотра, отмена последней правки, системное сохранение | Геометрический предпросмотр не доказывает безопасность неизвестных команд |
| Телеметрия | GRBL 1.1: состояния, MPos/WPos/WCO, рабочие X/Y/Z, feed/rapid override, входы | Нет телеметрии Marlin/EBB и старого формата статуса GRBL 0.9; отсутствующие координаты не выдумываются |
| Надёжность | Одна активная операция, отдельные realtime-байты, остановка на ALARM, блокировка после таймаута, EOF-обработка, ожидание планировщика | После аварийной остановки/потери синхронизации требуется переподключение; скорость отправки остаётся stop-and-wait |
| Desktop | Общее локальное ядро, системные диалоги файлов, USB/TCP, нативное меню рабочих пространств | macOS: Cmd+Shift+1/2; Windows: Ctrl+Shift+1/2 |

## Что уже было в OpenHand

Markdown/LaTeX, собственные однолинейные шрифты и кириллица, студия почерка,
фото-векторизация, импорт SVG и части ASCII DXF, XLSX/CSV/TSV таблицы,
G-code preview/import, GRBL/Marlin/EBB, USB/Bluetooth Serial/TCP, jog,
homing, ноль, перо, профили и калибровка, холостой прогон рамки, оптимизация
порядка штрихов, пауза/стоп, локальные точки восстановления заданий.
Наличие этих возможностей не означает идентичность их поведения GRBL-Plotter.

## Пока не перенесено

Это обновление **не обеспечивает полного паритета** с GRBL-Plotter.
Остаются отдельными подсистемами:

- Gerber и Excellon, полный HPGL (текст/шрифты/системы координат), полное DXF;
- QR/штрихкоды, dot-matrix, расширенные растровые стратегии;
- слои и цвета с таблицей инструментов, смена пера и автоматическая смена инструмента;
- разбиение рисунка на физические листы, продолжение контуров за границу плитки;
- компенсация ножа/радиуса, тангенциальная и поворотная оси, полярные координаты;
- редактирование отдельных объектов G-code и корректное преобразование дуг/модальных состояний;
- probing, карта высот, компенсация Z, камера и привязка по меткам;
- второй контроллер, дополнительные управляемые оси, геймпад;
- макросы, M98/M99, переменные и автоматизация процессов;
- character-counting streaming и полное согласование подтверждений/восстановления;
- email/push-уведомления, автоматическое переподключение и проверка частоты STEP.

Временная копия исходного репозитория удалена после анализа и не входит в проект.

## Плоттер с Ozon

Предоставлен текст карточки артикула 2121931195, продавец Jiahe Port.
В отзывах упомянуты китайское ПО, kwenjoy, Inkscape и UGS; точная модель
платы, версия прошивки, физические размеры рабочей области и команды
сервопривода не установлены. Метаданные карточки (AirPrint/Android/2.1 мм)
не используются как доказательство интерфейса управления.
Существующий пресет Ozon/KDraw — исходная настройка, не результат проверки
этого конкретного экземпляра. Реальное подключение и движения не выполнялись.

## Проверка

- 96 unit/in-memory serial tests: геометрия, форматы, ограничения, отверстия,
  байты realtime, межоперационная блокировка, ALARM, таймаут, EOF, финальный barrier.
- TypeScript: обычная и strict-конфигурация.
- Web: Vite production build и побайтовая проверка синхронизации `docs`/`macos/Web`.
- macOS: универсальная arm64/x86_64 сборка, ad-hoc подпись, открытие мастерской
  нативным меню, фигура в WKWebView и сохранение JSON через NSSavePanel.
- Windows: кросс-компиляция и self-contained Release ZIP WinForms/WebView2 для win-x64 на macOS;
  запуск готового приложения на Windows здесь не проверен.
- UI: браузер при широком и узком размере, фигура, штриховка, отмена;
  HPGL 60×40 мм импортирован через NSOpenPanel в macOS-приложении.
- Физический плоттер не использовался. Автотест транспорта использует
  виртуальный serial-поток и не доказывает совместимость прошивки.
