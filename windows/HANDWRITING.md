# Личный почерк

Windows включает общий пакет `docs` как `Web` через `OpenHand.csproj`.
Профиль «По умолчанию» включает те же 275 начертаний из 162 проверенных слов на 12 фото;
остальные буквы, цифры и знаки дополняются целыми траекториями автора из
бланка. Сохраняются боковые смещения, выбор по соседним буквам и миграция.
Общий предпросмотр и PDF используют плавную толщину шариковой линии
и локальную фактуру бумаги. Толщина линии на экране настраивается в
разделе «Почерк», фактура — в «Страница и поля». Прежняя версия сохранена.
Все шрифты поставляются локально; поведение совпадает с web-пакетом macOS.

Предпросмотр мастерской учитывает полную высоту выносов. Умещение слов
использует общий лимит сужения строки для предпросмотра и G-code.

[Источники, настройки, воспроизведение и ограничения](../font/pavel-notes/README.md).
Перед упаковкой выполняется `npm run build:web`. Windows EXE проверяется
командой `npm run windows:build` на Windows; на macOS упаковка не выполнялась.
