# Личный почерк

Windows включает общий пакет `docs` как `Web` через `OpenHand.csproj`.
Профиль «По умолчанию» включает те же 1026 реально написанных букв из 595
слов на 12 фото конспектов: у частых букв — десятки вариантов с настоящими
соединениями. Слово собирается целиком, поэтому соседние буквы из одного
сфотографированного слова пишутся вместе, а повтор слова выглядит иначе.
Буквы приведены к одному размеру, в слове не повторяются одной формой,
знаки препинания ставятся после чернил буквы. Знаки, которых нет в
конспектах, дополняются буквами автора из бланка.
Размер, шаг строки, пробелы и толщина линии измерены по фотографиям.
Все шрифты поставляются локально; поведение совпадает с web-пакетом macOS.

Предпросмотр мастерской учитывает полную высоту выносов. Умещение слов
использует общий лимит сужения строки для предпросмотра и G-code.

[Источники, настройки, воспроизведение и ограничения](../font/pavel-notes/README.md).
Перед упаковкой выполняется `npm run build:web`. Windows EXE проверяется
командой `npm run windows:build` на Windows; на macOS упаковка не выполнялась.
