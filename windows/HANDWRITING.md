# Персональный почерк

Windows использует общий профиль «По умолчанию» и инструмент
«Буква из конспекта» из web-сборки `docs`, которую OpenHand.csproj включает
в `Web`. Шрифт поставляется локально внутри сборки.

Исходники, настройки, образцы и ограничения: [font/pavel-notes](../font/pavel-notes/README.md).
Перед упаковкой выполняется `npm run build:web`, включая генерацию GFont.
Для проверки сборки Windows: `npm run windows:build` на Windows.

Обновление по IMG_0589–IMG_0601: те же 113 оцифрованных начертаний, варианты
окончаний и профиль 32 px / 1,18, ширина 82%. Общий код обновляет нетронутые настройки
прежнего профиля. Изменения включаются в установщик вместе с `docs`.

У 41 знака есть альтернативы. Индивидуальные интервалы форм сохраняются
в GFont; расчёт переносов учитывает выбранную форму и длинные петли.
Ручные настройки существующих документов сохраняются.
